 Install and configure `shadcn/ui`.

 Add these shadcn component:
-Button
-Card
-Dialog
-Input
-Tabs
-Textarea

Do not modify the generated `components/ui/*` file after installation.

Ensure all components match the exsiting dark theme in  `globals.css`.
